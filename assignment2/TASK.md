# Домашнее задание 2: Изучение представленности генов в таксонах

## Задачи

1. **Взять человеческий ген** — выбрать gene symbol.

   > Можно воспользоваться порталами NCBI Genes, OMIM или другими.

2. **Получить последовательность** выбранного гена в формате **FASTA**.

   > Можно воспользоваться базой NCBI Nucleotide.

3. **Найти гомологичные гены** — с помощью **NCBI BLAST** найти не менее **10** гомологичных генов в других видах.

   > Желательно, чтобы виды выходили за рамки отряда млекопитающих.

4. **Построить множественное выравнивание** — построить единое множественное выравнивание полученных последовательностей.

   > Можно воспользоваться online-версиями программ Muscle, MAFFT, Clustal Omega и других.

5. **Проанализировать выравнивание** с точки зрения консервативных участков.

6. **Определить ближайший объединяющий таксон** для видов, полученных в результате анализа, с помощью баз данных биологической систематики.

   > Например: Tree of Life Web Project, NCBI Taxonomy Browser, Global Biodiversity Information Facility.

## Что должно быть в GitHub-репозитории

1. Ответы на разминочные вопросы
2. Название выбранного гена (**Gene Symbol**)
3. Параметры **BLAST**, использованные для поиска гомологичных генов
4. Таблица с названиями полученных гомологичных генов (**Gene Symbol**), систематическими названиями видов и русскими названиями видов
5. Файл множественного выравнивания в формате **Clustal**
6. Краткий анализ консервативности полученного выравнивания в произвольной форме
7. Полученное название объединяющего таксона на латыни и на русском языке и краткое описание таксона в произвольной форме
